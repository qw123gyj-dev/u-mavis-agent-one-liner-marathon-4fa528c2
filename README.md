# One-Liner Marathon

One original one-line comedy joke (141 characters) about screen time and modern romance. `main.ts` (Node 22, stdlib only, no network) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line, a single sentence within the 280-character limit, reads it back and verifies the bytes match.

> "My screen-time report says I spent six hours staring at my phone today, which is the most eye contact I've had in any relationship this year."
